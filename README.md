# 配网终端通讯工具（104 / 101 模拟主站）

Windows 桌面工具：IEC 60870-5-104（TCP）与 IEC 60870-5-101（串口 FT1.2，平衡/非平衡）模拟主站，
支持四遥测试、本地固定 IP/端口绑定、事件记录与四遥统计。

## 启动

```bash
cd 配网终端通讯
python -m app.main
```

或：

```bash
python app/main.py
```

可选 WebView 界面（需 pywebview，默认仍为 Tk）：

```bash
set PEIWANG_USE_WEBVIEW=1
python -m app.main
```

## 功能

- **104 主站**：连接、T0~T3/K/W 参数、STARTDT/TESTFR 链路保持、总召唤、时钟同步、自动重连
- **101 主站（串口）**：
  - 非平衡方式：复位链路 → 请求链路状态 → 周期召唤 2 级数据；收到 ACD=1 自动召唤 1 级数据；用户数据(FC=3)等 ACK
  - 平衡方式：DIR/FCB 控制域，用户数据确认(FC=4)，双方均可发起传输
  - FT1.2 固定帧/可变帧/单字符帧编解码，链路地址 1 或 2 字节
- **四遥**：遥信/遥测监视，单/双点遥控（SBO 预选-执行-撤销），浮点/归一化设点，定值区读取/切换与整区固化
- **事件记录**：SOE（时标遥信）、COS 变位、遥控/遥调操作、链路启停
- **四遥统计**：变位次数、SOE 数量、遥测越限/突变死区/长期不变、遥控与遥调次数
- **本地绑定**：多网卡列表、指定本地 IP、可选本地端口、失败分类提示
- **多主站会话**：可同时维护多路 104/101 会话
- **点表管理**：JSON 工程保存、CSV 发码表导入

## 101 使用步骤

1. 「连接参数」区把「协议」选为 **101**，界面会切换到串口参数；
2. 选择串口（点「刷新串口」枚举本机串口）、波特率、校验（N/E/O）、停止位；
3. 设置链路地址（1~255 用 1 字节，>255 自动用 2 字节）与**链路地址长度**（默认 2 字节，国内常见；部分现场 1 字节）、是否「平衡方式」、非平衡轮询周期；
4. 「信息体地址长度」默认 2 字节（国内常见），个别厂家用 3 字节；
5. 点「连接」：工具自动复位链路(FC=0)、请求链路状态(FC=9)；非平衡方式随后按周期轮询 2 级数据。

> 公共地址(CA)/源发地址(OA)对 101/104 均有效；101 的 ASDU 编解码与 104 共用，默认信息体地址 2 字节。

## 模拟自测（无需真实装置）

内置内存回环的模拟从站，可在没有硬件/串口的情况下验证 101 全流程：

```bash
python scripts/sim_iec101.py       # FT1.2 编解码往返 + 非平衡/平衡主站全流程
python scripts/sim_iec101_api.py   # API 层集成（串口枚举、事件、四遥统计、遥控、校时）
```

## 依赖说明

- `pyserial`：101 串口通信
- 可选 `pywebview`：WebView 界面（见 `requirements.txt`）；未安装时自动回退 Tk
- 协议层当前为自研 Python 实现（满足本地 bind）；后续可桥接 c104 / lib60870（GPL）

## 打包

```bash
python scripts/build_exe.py
```

产物：`dist\配网终端通讯\配网终端通讯.exe`（需整目录发布）。
若旧 exe 仍在运行，打包会因目录占用失败，请先结束进程。
